# Comment Reflow

Tidy Xcode DocC comments in one keystroke.

Comment Reflow is an Xcode Source Editor Extension for macOS that reflows long `//` and `///` comments to a column width you choose. Indentation, comment markers, and DocC structure stay correct on every line – even across multiple comment blocks at once. Place your cursor in a comment, select a range, or select an entire file, then run one command.

## Key Features

- Reflows `//` line comments and `///` DocC documentation comments to a configurable column width (72 by default)
- Preserves indentation and comment markers on every line
- Re-wraps DocC structure correctly – parameter lists, bullet points, code blocks, and callouts
- Reflows a single comment, a selection, or an entire file in one pass while leaving your code untouched
- Run "Reflow Line Comments" from Xcode's Editor menu or assign your own keyboard shortcut
- Lightweight Xcode extension – no changes to your project files or build settings
- 100% local – no accounts, no servers, no trackers, no ads
- Free

Whether you pasted a long comment into Swift code or edited a single word in a DocC parameter description, Comment Reflow takes the manual re-wrapping out of your day.
